## Icons

Use `startIcon` or `endIcon` to embed a decorative icon inside the field. Icons are sized automatically to match the `size` prop.

<Showcase title="Icons" code={`import { Search, Mail } from 'lucide-react'\n\n<Input startIcon={<Search />} placeholder="Search…" />\n<Input startIcon={<Mail />} placeholder="Email address" type="email" />`}>

## Error state

Add `error` to apply destructive border and ring. Pair with `FormMessage` for the error text.

## Clearable

Set `clearable` and pass `value` + `onClear` to show a × button when the field has a value.

<Showcase title="Clearable" code={`'use client'\nimport { useState } from 'react'\n\nconst [value, setValue] = useState('')\n\n<Input\n  value={value}\n  onChange={(e) => setValue(e.target.value)}\n  onClear={() => setValue('')}\n  clearable\n  placeholder="Type something…"\n/>`}>
  <InputClearablePreview />
</Showcase>

## API

| Prop | Type | Default | Description |
|---|---|---|---|
| `size` | `sm \| default \| lg` | `default` | Field height and text size |
| `error` | `boolean` | `false` | Applies destructive border and ring |
| `startIcon` | `ReactNode` | — | Icon rendered inside the left edge |
| `endIcon` | `ReactNode` | — | Icon rendered inside the right edge |
| `clearable` | `boolean` | `false` | Shows × button when field has a value |
| `onClear` | `() => void` | — | Called when × is clicked |
| `type` | `string` | `text` | Native input type; `password` enables visibility toggle |
| `disabled` | `boolean` | `false` | Prevents interaction |
| `className` | `string` | — | Additional class names |

`Input` forwards all standard `<input>` HTML attributes and accepts a `ref`.
