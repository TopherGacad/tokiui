# Input

A styled text input field. Forwards all native `<input>` attributes.

## Usage

```tsx
import { Input } from '@/components/ui/input'

<Input placeholder="Enter a value" />
```

## Props

| Prop | Type | Default |
|---|---|---|
| `type` | `string` | `text` |
| `placeholder` | `string` | — |
| `disabled` | `boolean` | `false` |
| `className` | `string` | — |

`Input` forwards all standard `<input>` HTML attributes and accepts a `ref`.
