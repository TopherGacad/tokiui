## Setup

`TooltipProvider` must wrap your app once. It's already included in the tokiui root layout setup.

```tsx
// app/layout.tsx
import { TooltipProvider } from '@tokiui/ui'

export default function RootLayout({ children }) {
  return (
    <html>
      <body>
        <TooltipProvider>{children}</TooltipProvider>
      </body>
    </html>
  )
}
```

## Disabled elements

Disabled HTML elements don't fire pointer events, so the tooltip won't trigger. Wrap the disabled element in a `<span>` to receive the events instead.

<Showcase title="Disabled element" code={`<Tooltip>
  <TooltipTrigger asChild>
    {/* span receives pointer events; button is visually disabled */}
    <span tabIndex={0} className="cursor-not-allowed inline-block">
      <Button disabled style={{ pointerEvents: 'none' }}>Publish</Button>
    </span>
  </TooltipTrigger>
  <TooltipContent>You need editor permissions to publish.</TooltipContent>
</Tooltip>`}>
  <TooltipDisabledPreview />
</Showcase>

## API

### Tooltip (root)

| Prop | Type | Default | Description |
|---|---|---|---|
| `delayDuration` | `number` | `700` | Delay in ms before tooltip opens |
| `closeDelay` | `number` | — | Delay in ms before tooltip closes after cursor leaves |
| `open` | `boolean` | — | Controlled open state |
| `onOpenChange` | `(open: boolean) => void` | — | Called when open state changes |
| `defaultOpen` | `boolean` | `false` | Uncontrolled initial open state |
| `disableHoverableContent` | `boolean` | `false` | Close when cursor moves to tooltip content |

### TooltipContent

| Prop | Type | Default | Description |
|---|---|---|---|
| `size` | `'sm' \| 'default'` | `'default'` | Text size and padding |
| `arrow` | `boolean` | `false` | Show a triangular arrow pointing to the trigger |
| `side` | `'top' \| 'right' \| 'bottom' \| 'left'` | `'top'` | Preferred side |
| `sideOffset` | `number` | `6` | Distance from trigger in px |
| `align` | `'start' \| 'center' \| 'end'` | `'center'` | Alignment along the side |
| `className` | `string` | — | Merged with content class list |

### TooltipProvider

| Prop | Type | Default | Description |
|---|---|---|---|
| `delayDuration` | `number` | `700` | Default delay for all tooltips |
| `skipDelayDuration` | `number` | `300` | Time before delay resets after last tooltip |

## Accessibility

- Tooltip content is announced by screen readers via `role="tooltip"`
- Triggers must be focusable — always use `asChild` with a real interactive element
- Tooltips appear on both hover and keyboard focus
- Do not put critical information only in a tooltip — it is invisible on touch devices
- Tooltip text should complement the element's existing accessible name, not replace it
