# Card

A contained surface for grouping related content. Composed from sub-components for flexible layouts.

## Usage

```tsx
import {
  Card,
  CardHeader,
  CardTitle,
  CardDescription,
  CardContent,
  CardFooter,
} from '@/components/ui/card'
```

## Sub-components

| Component | Element | Description |
|---|---|---|
| `Card` | `div` | Outer container with border and background |
| `CardHeader` | `div` | Top section — holds title and description |
| `CardTitle` | `h3` | Primary heading inside the header |
| `CardDescription` | `p` | Secondary text inside the header |
| `CardContent` | `div` | Main body area |
| `CardFooter` | `div` | Bottom row — typically holds actions |

All sub-components accept `className` and a `ref`, and forward all standard HTML `div` attributes.
