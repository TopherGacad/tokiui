## Status border

A colored left border communicates status without disrupting layout. Use with alerts, log entries, and notification cards.

<Showcase title="Status border" code={`<Card status="success">…</Card>\n<Card status="warning">…</Card>\n<Card status="info">…</Card>\n<Card status="destructive">…</Card>`}>

## Interactive

Add `interactive` for a hover lift effect on clickable cards. Pairs with an `onClick` or wrapping `<a>` tag.

<Showcase title="Interactive" code={`<Card interactive onClick={() => openIntegration(name)}>\n  <CardContent>\n    <p>{name}</p>\n  </CardContent>\n</Card>`}>

## CardImage

Use `CardImage` to add a media slot at the top of the card. The `aspectRatio` prop constrains the image container.

<Showcase title="CardImage" code={`<Card>
  <CardImage
    src="/trail.jpg"
    alt="Mountain landscape"
    aspectRatio="16/9"
  />
  <CardHeader>
    <CardTitle>Mountain Trail</CardTitle>
    <CardDescription>A scenic route through alpine terrain.</CardDescription>
  </CardHeader>
</Card>`}>
  <CardImagePreview />
</Showcase>

## API

### Card

| Prop | Type | Default | Description |
|---|---|---|---|
| `shadow` | `none \| sm \| md \| lg` | `sm` | Box shadow level |
| `status` | `none \| success \| warning \| info \| destructive` | `none` | Colored left border |
| `interactive` | `boolean` | `false` | Hover lift and active scale effect |
| `className` | `string` | — | Additional class names |

### CardImage

| Prop | Type | Default | Description |
|---|---|---|---|
| `src` | `string` | — | Image source URL |
| `alt` | `string` | `''` | Alt text for the image |
| `aspectRatio` | `16/9 \| 4/3 \| 1/1 \| 3/2` | `16/9` | Constrains the image container height |

### Sub-components

| Component | Element | Description |
|---|---|---|
| `CardHeader` | `div` | Top section — holds title and description |
| `CardTitle` | `h3` | Primary heading |
| `CardDescription` | `p` | Secondary muted text |
| `CardContent` | `div` | Main body area |
| `CardFooter` | `div` | Bottom row — typically holds actions |

All sub-components accept `className`, a `ref`, and forward all standard HTML attributes.
