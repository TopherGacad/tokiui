## API

### Skeleton

| Prop | Type | Default | Description |
|---|---|---|---|
| `variant` | `default \| circle \| text` | `default` | Shape — `default` is a rounded rectangle, `circle` is fully rounded, `text` is a thin full-width line |
| `animation` | `pulse \| shimmer \| none` | `pulse` | Loading animation style |
| `className` | `string` | — | Use to set `width` and `height` (e.g. `w-48 h-6`) |

## Customization

### Color

Skeletons use the `--skeleton-bg` CSS variable. Override it globally in your theme or locally on a wrapper to change the skeleton color across a section:

```css
/* global override in your globals.css */
:root        { --skeleton-bg: oklch(0.93 0.01 250); } /* custom tint */
[data-theme="dark"] { --skeleton-bg: oklch(0.32 0.01 250); }
```

```tsx
{/* scoped override — only affects skeletons inside this div */}
<div style={{ '--skeleton-bg': 'oklch(0.90 0.02 145)' } as React.CSSProperties}>
  <Skeleton className="h-4 w-48" />
</div>
```

### One-off color via className

For a single skeleton that needs a different color, pass a background class directly. This overrides `--skeleton-bg` for that element only:

```tsx
<Skeleton className="h-4 w-48 bg-primary/15" />
<Skeleton className="h-4 w-48 bg-blue-200 dark:bg-blue-900" />
```

### Opacity

`animate-pulse` uses Tailwind's built-in opacity animation. You can slow it down or adjust the range with arbitrary animation utilities:

```tsx
{/* slower pulse */}
<Skeleton className="h-4 w-48 [animation-duration:3s]" />
```

## Accessibility

- `aria-hidden="true"` is set automatically — skeletons are decorative and screen readers ignore them
- Pair with a live region (`aria-live="polite"`) on the content container so screen readers announce when real content replaces the skeleton
- Respects `prefers-reduced-motion` — both `pulse` and `shimmer` animations are disabled automatically
