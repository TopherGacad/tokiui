## Customization

The separator uses the `--separator-color` CSS variable. Override it to change the line color globally or within a scoped container:

```css
/* global override */
:root             { --separator-color: oklch(0.80 0.01 250); }
[data-theme="dark"] { --separator-color: oklch(0.45 0.01 250); }
```

```tsx
{/* scoped override */}
<div style={{ '--separator-color': 'var(--primary)' } as React.CSSProperties}>
  <Separator />
</div>
```

For a one-off color, pass a background class directly via `className`:

```tsx
<Separator className="bg-primary/30" />
<Separator className="bg-destructive/40" />
```

## API

### Separator

| Prop | Type | Default | Description |
|---|---|---|---|
| `orientation` | `horizontal \| vertical` | `horizontal` | Direction of the dividing line |
| `decorative` | `boolean` | `true` | When `true`, hidden from screen readers (`role="none"`). Set to `false` when the separator marks a meaningful section boundary |
| `className` | `string` | — | Use to control length — e.g. `h-4` for a vertical separator, or `bg-*` to override color |

## Accessibility

- `decorative={true}` (default) sets `role="none"` — the line is skipped by screen readers
- `decorative={false}` sets `role="separator"` and `aria-orientation` — use this when the separator marks a meaningful section boundary
