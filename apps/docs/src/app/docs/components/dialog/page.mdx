# Dialog

A modal dialog built on Radix UI. Includes focus trapping, Escape to close, and scroll lock.

## Usage

```tsx
import {
  Dialog,
  DialogTrigger,
  DialogContent,
  DialogHeader,
  DialogTitle,
  DialogDescription,
  DialogFooter,
  DialogClose,
} from '@/components/ui/dialog'
```

## Accessibility

- Focus is trapped inside the dialog while open
- Pressing `Escape` closes the dialog
- Scroll is locked on the body while open
- `DialogTitle` is required — it becomes the `aria-labelledby` for the dialog
- `DialogDescription` is optional but recommended for `aria-describedby`

## Sub-components

| Component | Description |
|---|---|
| `Dialog` | Root state container |
| `DialogTrigger` | Element that opens the dialog — use `asChild` to avoid a wrapper |
| `DialogContent` | The panel rendered inside the overlay — includes the close button |
| `DialogOverlay` | The backdrop — rendered automatically by `DialogContent` |
| `DialogHeader` | Top section wrapping title and description |
| `DialogTitle` | Required accessible title |
| `DialogDescription` | Optional accessible description |
| `DialogFooter` | Bottom row for actions |
| `DialogClose` | Element that closes the dialog — use `asChild` to wrap your own button |
| `DialogPortal` | Renders content into `document.body` — used internally by `DialogContent` |
