## API

### NavigationMenu

Root element. Automatically renders the `NavigationMenuViewport` below the list. Accepts all Radix `NavigationMenu.Root` props.

### NavigationMenuList

The `<ul>` container that holds `NavigationMenuItem` elements. Renders as a horizontal flex row.

### NavigationMenuItem

Wraps a single item — either a `NavigationMenuTrigger` + `NavigationMenuContent` pair, or a standalone `NavigationMenuLink`.

### NavigationMenuTrigger

A button that opens its sibling `NavigationMenuContent`. Includes a chevron that rotates on open.

| Prop | Type | Notes |
|---|---|---|
| All `<button>` props | — | Passed through to the underlying button element |

### NavigationMenuContent

The panel rendered inside the viewport when the parent trigger is open. Animates in/out with directional slide transitions when navigating between triggers.

### NavigationMenuLink

A styled `<a>` (or `asChild` component) for direct navigation — no dropdown. Apply your own hover/focus classes to match your design.

### NavigationMenuViewport

The floating container that hosts `NavigationMenuContent` panels. Automatically included inside `NavigationMenu` — only export separately if you need to override its positioning.

### NavigationMenuIndicator

Optional animated caret that points from the active trigger to the open viewport. Rendered inside `NavigationMenuList`.

## Accessibility

- Full keyboard support: `Tab` to focus triggers, `Enter`/`Space` to open, `Escape` to close, `ArrowLeft`/`ArrowRight` to move between triggers
- `aria-expanded` on triggers, `aria-controls` linking trigger to content
- Focus is trapped inside the open content panel until dismissed
