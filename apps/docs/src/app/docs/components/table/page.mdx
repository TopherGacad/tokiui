## Data table

The primitives are unopinionated, so you compose them with your own state for sorting, pagination, row selection, and row actions — no data-grid dependency. This example pairs `Table` with `useState` + `Checkbox`, `Badge`, `Button`, `Pagination`, and `DropdownMenu`. Click the **Amount** or **Date** headers to sort, page through with the controls, select rows with the checkboxes, and open the **⋯** menu on any row for actions.

## Accessibility

- Renders semantic `<table>` / `<thead>` / `<tbody>` / `<tr>` / `<th>` / `<td>` — assistive tech announces rows, columns, and headers natively.
- Use `TableHead` for header cells so data cells associate with the correct column.
- In interactive tables, label controls (`aria-label` on selection checkboxes) and reflect selection with `data-state="selected"` on the row.
- Add a `TableCaption` (or an adjacent heading) describing the table.
