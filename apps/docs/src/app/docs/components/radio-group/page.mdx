## Card style

Wrap each item in a styled `<label>` to create a card-style selector with highlighted selection.

<Showcase title="Card style" code={`'use client'

const PLANS = [
  { value: 'starter', label: 'Starter', price: '$0',  desc: 'For personal projects' },
  { value: 'pro',     label: 'Pro',     price: '$12', desc: 'For growing teams'      },
]

export function PlanPicker() {
  const [value, setValue] = useState('pro')

  return (
    <RadioGroup value={value} onValueChange={setValue} style={{ gap: 8 }}>
      {PLANS.map((plan) => (
        <label
          key={plan.value}
          htmlFor={\`plan-\${plan.value}\`}
          style={{
            display: 'flex', alignItems: 'center', gap: 12,
            padding: '12px 14px', borderRadius: 'var(--radius-sm)',
            border: \`1px solid \${value === plan.value ? 'var(--primary)' : 'var(--border)'}\`,
            background: value === plan.value
              ? 'color-mix(in oklch, var(--primary) 6%, var(--background))'
              : 'var(--background)',
            cursor: 'pointer', transition: 'all 0.15s',
          }}
        >
          <RadioGroupItem id={\`plan-\${plan.value}\`} value={plan.value} />
          <span style={{ flex: 1 }}>
            <span style={{ fontSize: 14, fontWeight: 500 }}>{plan.label}</span>
            <span style={{ display: 'block', fontSize: 12, color: 'var(--muted-foreground)' }}>{plan.desc}</span>
          </span>
          <span style={{ fontSize: 14, fontWeight: 600, color: 'var(--primary)' }}>{plan.price}/mo</span>
        </label>
      ))}
    </RadioGroup>
  )
}`}>
  <RadioGroupCardPreview />

## API

### RadioGroup

| Prop | Type | Default | Description |
|---|---|---|---|
| `size` | `sm \| default \| lg` | `default` | Size inherited by all items |
| `color` | `default \| success \| warning \| info \| destructive` | `default` | Checked color inherited by all items |
| `error` | `boolean` | `false` | Applies destructive border to all items |
| `value` | `string` | — | Controlled selected value |
| `defaultValue` | `string` | — | Uncontrolled initial value |
| `onValueChange` | `(value: string) => void` | — | Called when selection changes |
| `disabled` | `boolean` | `false` | Disables all items in the group |
| `required` | `boolean` | `false` | Marks the group as required in a form |
| `name` | `string` | — | Input name for form submission |
| `orientation` | `horizontal \| vertical` | `vertical` | Layout and arrow key navigation direction |
| `className` | `string` | — | Additional class names |

### RadioGroupItem

| Prop | Type | Default | Description |
|---|---|---|---|
| `value` | `string` | **required** | The value this item represents |
| `size` | `sm \| default \| lg` | — | Overrides the group size for this item |
| `color` | `default \| success \| warning \| info \| destructive` | — | Overrides the group color for this item |
| `error` | `boolean` | — | Overrides the group error state for this item |
| `disabled` | `boolean` | `false` | Disables this specific item |
| `className` | `string` | — | Additional class names |

## Accessibility

- Arrow keys (`↑` `↓` or `←` `→`) move between items; `Space` selects the focused item
- `RadioGroup` renders as `role="radiogroup"`; each item as `role="radio"` with `aria-checked`
- Connect a visible `<label>` using `htmlFor` matching each item's `id`
- Disabled items have `aria-disabled="true"` and are skipped during keyboard navigation
