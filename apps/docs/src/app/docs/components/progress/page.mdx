`color` maps to the semantic palette. Use `success`, `warning`, `info`, or `error` when the value carries status meaning.

`variant="striped"` adds animated diagonal stripes. Combine with any color.

Use `variant="indeterminate"` when the duration is unknown — the bar loops indefinitely without a `value`.

## API

### Progress

| Prop | Type | Default | Description |
|---|---|---|---|
| `value` | `number` | `0` | Current progress value |
| `max` | `number` | `100` | Maximum value — `value / max` is used to compute percentage |
| `size` | `sm \| default \| lg` | `default` | Track height |
| `color` | `default \| success \| warning \| info \| error` | `default` | Fill color |
| `variant` | `default \| striped \| indeterminate` | `default` | Visual style — `indeterminate` ignores `value` |
| `showLabel` | `boolean` | `false` | Render a label row above the bar |
| `label` | `string` | — | Label text and accessible name. Defaults to `"Progress"` |

## Accessibility

- The track element carries `role="progressbar"` with `aria-valuenow`, `aria-valuemin`, and `aria-valuemax`
- `aria-valuenow` is omitted for `variant="indeterminate"` per the ARIA spec
- Pass `label` to provide a meaningful accessible name beyond the default `"Progress"`
- Both `striped` and `indeterminate` animations respect `prefers-reduced-motion` — they stop when the user has requested reduced motion
