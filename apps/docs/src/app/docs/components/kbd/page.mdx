## Accessibility

- Renders the native `<kbd>` element, which assistive tech recognizes as keyboard input.
- For multi-key shortcuts, give the wrapping element a descriptive `aria-label` (e.g. `aria-label="Command K"`) — screen readers read glyphs like ⌘ and ⇧ inconsistently.
- `Kbd` is presentational; wire the actual shortcut with a key handler and reflect it here.
