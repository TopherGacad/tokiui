## API

### AreaChart

| Prop | Type | Default | Description |
|---|---|---|---|
| `data` | `number[]` | — | Series values (required) |
| `compare` | `number[]` | — | Optional second, dashed baseline series |
| `labels` | `string[]` | — | X-axis labels; also shown in the hover tooltip |
| `color` | `string` | `var(--primary)` | Line and fill color |
| `height` | `number` | `220` | Plot height in px |
| `showTooltip` | `boolean` | `true` | Hover crosshair + value tooltip |
| `valueFormat` | `(v: number) => string` | — | Formats the tooltip value |
| `className` | `string` | — | Additional class names |

### BarChart

| Prop | Type | Default | Description |
|---|---|---|---|
| `data` | `number[]` | — | Bar values (required) |
| `labels` | `string[]` | — | X-axis labels; also shown on hover |
| `color` | `string` | `var(--primary)` | Bar color |
| `height` | `number` | `220` | Chart height in px |
| `showTooltip` | `boolean` | `true` | Hover highlight + value tooltip |
| `valueFormat` | `(v: number) => string` | — | Formats the tooltip value |
| `className` | `string` | — | Additional class names |

### DonutChart

| Prop | Type | Default | Description |
|---|---|---|---|
| `data` | `DonutSegment[]` | — | Segments of `{ label?, value, color }` (required) |

| `thickness` | `number` | `18` | Ring thickness in px |
| `children` | `ReactNode` | — | Rendered centered inside the ring |

## When to reach for a charting library

These charts are **presentational** — perfect for dashboards, KPI cards, and summaries, with no dependencies and full token theming. For heavy data-viz (zoom/pan, brushing, smart axes, tens of thousands of points, real-time streams), drop a dedicated library like Recharts into that one view.

## Accessibility

- The SVGs are marked `aria-hidden` (decorative). Pair a chart with a visible figure/summary or a `<table>` of the same data so the information isn't conveyed by color/shape alone.
- The hover tooltip is a progressive enhancement — all values should also be available as text (labels, totals, a legend).
