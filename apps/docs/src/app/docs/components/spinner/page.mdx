## API

### Spinner

| Prop | Type | Default | Description |
|---|---|---|---|
| `variant` | `arc \| ring \| dots \| bars` | `arc` | Visual design of the spinner |
| `size` | `sm \| default \| lg \| xl` | `default` | Diameter of the spinner |
| `color` | `default \| current \| neutral \| white \| green \| amber \| sky \| red` | `default` | Color of the spinner |
| `label` | `string` | `'Loading…'` | Accessible label read by screen readers |
| `className` | `string` | — | Additional class names |

## Accessibility

- Uses `role="status"` so screen readers announce it as a live region
- `aria-label` defaults to `'Loading…'` — pass a more descriptive label when context matters (e.g. `label="Saving your changes"`)
- Respects `prefers-reduced-motion` — all animations are disabled for users who prefer reduced motion
