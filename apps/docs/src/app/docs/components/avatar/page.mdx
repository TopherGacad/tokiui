## Auto color

Set `color="auto"` to deterministically derive a color from the `fallback` string. The same name always resolves to the same color — useful in user lists where manual color assignment would be impractical.

<Showcase title="Auto color" code={`<Avatar color="auto" fallback="ML" />\n<Avatar color="auto" fallback="ST" />\n<Avatar color="auto" fallback="RC" />`}>

## API

### Avatar

| Prop | Type | Default | Description |
|---|---|---|---|
| `src` | `string` | — | Image URL. Falls back to `fallback` or icon on error |
| `alt` | `string` | `""` | Alt text for the image (also used as `aria-label` for fallback) |
| `fallback` | `string` | — | Initials or short text to display when no image is available |
| `color` | `auto \| default \| primary \| green \| amber \| sky \| red \| slate` | `"default"` | Background color. Use `"auto"` to derive color from `fallback` |
| `status` | `AvatarStatus` | — | Presence indicator dot: `online`, `offline`, `busy`, or `away` |
| `size` | `sm \| default \| lg \| xl` | `default` | Controls diameter and font size |
| `className` | `string` | — | Appended to the root element |

### AvatarGroup

| Prop | Type | Default | Description |
|---|---|---|---|
| `size` | `sm \| default \| lg \| xl` | `default` | Passed to every child `Avatar` and controls overlap spacing |
| `max` | `number` | — | Maximum avatars to display. Overflow shown as `+N` |
| `className` | `string` | — | Appended to the group container |

## Accessibility

- When `src` is set, `alt` is forwarded to the `<img>` element
- When showing fallback initials, `alt` is used as `aria-label` on the text node
- The default user icon is `aria-hidden="true"`
- Status dots have an `aria-label` matching the status string
