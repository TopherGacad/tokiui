## API

### Select (root)

| Prop | Type | Default | Description |
|---|---|---|---|
| `value` | `string` | — | Controlled selected value |
| `onValueChange` | `(value: string) => void` | — | Called when selection changes |
| `defaultValue` | `string` | — | Uncontrolled initial value |
| `disabled` | `boolean` | `false` | Disables the entire select |
| `open` | `boolean` | — | Controlled open state |
| `onOpenChange` | `(open: boolean) => void` | — | Called when open state changes |

### SelectTrigger

| Prop | Type | Default | Description |
|---|---|---|---|
| `size` | `sm \| default \| lg` | `default` | Trigger height and text size |
| `error` | `boolean` | `false` | Applies destructive border and ring |
| `clearable` | `boolean` | `false` | Shows × button when a value is selected |
| `onClear` | `() => void` | — | Called when × is clicked — use to reset the value |
| `disabled` | `boolean` | `false` | Disables the trigger independently |
| `className` | `string` | — | Additional class names — use for width |

### SelectContent

| Prop | Type | Default | Description |
|---|---|---|---|
| `position` | `'popper' \| 'item-aligned'` | `'popper'` | `popper` anchors below trigger; `item-aligned` aligns selected item with trigger |
| `side` | `'top' \| 'right' \| 'bottom' \| 'left'` | `'bottom'` | Preferred side |
| `sideOffset` | `number` | `4` | Distance from trigger in px |
| `align` | `'start' \| 'center' \| 'end'` | `'start'` | Alignment along the side |

### SelectItem

| Prop | Type | Default | Description |
|---|---|---|---|
| `value` | `string` | **required** | The value submitted when this item is selected |
| `disabled` | `boolean` | `false` | Prevents selection of this item |

## Sub-components

| Component | Description |
|---|---|
| `Select` | Root state container |
| `SelectTrigger` | The button that opens the dropdown — styled like an Input |
| `SelectValue` | Renders selected item text or placeholder |
| `SelectContent` | The dropdown panel |
| `SelectItem` | A single option |
| `SelectGroup` | Groups related items together |
| `SelectLabel` | Non-interactive label for a group |
| `SelectSeparator` | Horizontal divider between groups |
| `SelectScrollUpButton` | Appears at top when content overflows |
| `SelectScrollDownButton` | Appears at bottom when content overflows |

## Accessibility

- Full keyboard navigation: `↑` `↓` to move, `Enter` / `Space` to select, `Escape` to close
- `SelectTrigger` uses `role="combobox"` with `aria-expanded` and `aria-haspopup`
- Selected item is announced by screen readers via `aria-selected`
- Connect a visible `<label>` using `htmlFor` matching the trigger's `id`
- Disabled items use `aria-disabled="true"` and are skipped during keyboard navigation
