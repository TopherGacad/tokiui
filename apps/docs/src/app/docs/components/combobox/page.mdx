## Accessibility

- The search field is a `role="combobox"` with `aria-controls`, `aria-autocomplete="list"`, and `aria-activedescendant` tracking the highlighted option.
- The list is a `role="listbox"`; each item is a `role="option"` with `aria-selected`.
- **Keyboard:** type to filter, <kbd className="kbd">↑</kbd> / <kbd className="kbd">↓</kbd> to move, <kbd className="kbd">Enter</kbd> to select, <kbd className="kbd">Esc</kbd> to close. Focus moves to the search field on open.
- Disabled options set `aria-disabled` and are skipped on selection.
