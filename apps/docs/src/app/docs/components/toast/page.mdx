## Setup

Add `<Toaster />` once in your root layout. All `toast()` calls anywhere in your app will appear there.

```tsx
// app/layout.tsx
import { Toaster } from '@tokiui/ui'

export default function RootLayout({ children }) {
  return (
    <html>
      <body>
        {children}
        <Toaster />
      </body>
    </html>
  )
}
```

## Import

```tsx
import { toast } from '@tokiui/ui'
```

## Promise

`toast.promise` shows loading → success/error automatically as the promise resolves. Ideal for async operations like file uploads, form submissions, or API calls.

## Position

Set `position` on `<Toaster />` in your root layout to control where all toasts appear. The default is `bottom-right`.

<Showcase title="Position" code={`// In your root layout:
<Toaster position="top-right" />

// All positions:
// top-left | top-center | top-right
// bottom-left | bottom-center | bottom-right`}>
  <ToastPositionPreview />
</Showcase>

## Duration

Control how long a toast stays visible with the `duration` option in milliseconds. Pass `Infinity` for a persistent toast that only closes when dismissed.

<Showcase title="Duration" code={`toast('Dismisses in 2 seconds.', { duration: 2000 })
toast('Dismisses in 8 seconds.', { duration: 8000 })
toast('Stays until dismissed.', { duration: Infinity })`}>
  <ToastDurationPreview />
</Showcase>

## API

### Toaster props

| Prop | Type | Default | Description |
|---|---|---|---|
| `position` | `'top-left' \| 'top-center' \| 'top-right' \| 'bottom-left' \| 'bottom-center' \| 'bottom-right'` | `'bottom-right'` | Where toasts appear |
| `duration` | `number` | `5000` | Default auto-dismiss duration in ms |
| `richColors` | `boolean` | `true` | Use semantic colors for success/error/info/warning |
| `closeButton` | `boolean` | `true` | Show a close button on each toast |
| `expand` | `boolean` | `false` | Expand all toasts instead of stacking |
| `visibleToasts` | `number` | `3` | Max toasts visible at once |

### toast() options

| Option | Type | Default | Description |
|---|---|---|---|
| `description` | `string \| ReactNode` | — | Secondary line below the title |
| `duration` | `number` | `5000` | Auto-dismiss duration in ms |
| `position` | `Position` | Toaster default | Override position for this toast |
| `action` | `{ label: string, onClick: () => void }` | — | Action button |
| `cancel` | `{ label: string, onClick: () => void }` | — | Cancel button |
| `onDismiss` | `(toast) => void` | — | Called when toast is dismissed |
| `onAutoClose` | `(toast) => void` | — | Called when toast auto-closes |
| `id` | `string \| number` | auto | Custom ID — useful for deduplication |

## Accessibility

- Toasts use `role="status"` (default) or `role="alert"` for errors so screen readers announce them
- The close button is keyboard accessible
- Toasts do not steal focus — they are non-blocking by design
- Avoid putting critical information only in a toast — it auto-dismisses and may be missed
- Use `duration: Infinity` when the user must acknowledge the notification
