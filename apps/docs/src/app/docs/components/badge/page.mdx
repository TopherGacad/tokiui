## API

| Prop | Type | Default | Description |
|---|---|---|---|
| `variant` | `solid \| soft \| outline` | `solid` | Visual fill style |
| `color` | `default \| secondary \| destructive \| success \| warning \| info` | `default` | Semantic color |
| `size` | `sm \| md \| lg` | `md` | Badge size |
| `dot` | `boolean` | `false` | Prepends a status dot |
| `onDismiss` | `() => void` | — | Renders a dismiss × button and calls this on click |
| `className` | `string` | — | Additional class names |

`Badge` forwards all standard `<span>` HTML attributes and accepts a `ref`.
