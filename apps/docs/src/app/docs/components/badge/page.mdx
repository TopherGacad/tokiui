# Badge

Displays a short status label or category tag. Supports four variants.

## Usage

```tsx
import { Badge } from '@/components/ui/badge'

<Badge>New</Badge>
```

## Props

| Prop | Type | Default |
|---|---|---|
| `variant` | `default \| secondary \| outline \| destructive` | `default` |
| `className` | `string` | — |

`Badge` forwards all standard `<span>` HTML attributes and accepts a `ref`.
