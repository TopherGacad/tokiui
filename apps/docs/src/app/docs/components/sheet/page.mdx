## Import

```tsx

  Sheet,
  SheetTrigger,
  SheetClose,
  SheetContent,
  SheetHeader,
  SheetFooter,
  SheetTitle,
  SheetDescription,
  SheetBody,
} from '@tokiui/ui'
```

## Sides

Use the `side` prop on `SheetContent` to control which edge the panel slides in from. Defaults to `right`.

## API

### Sheet

| Prop | Type | Default | Description |
|---|---|---|---|
| `open` | `boolean` | — | Controlled open state |
| `defaultOpen` | `boolean` | `false` | Uncontrolled initial open state |
| `onOpenChange` | `(open: boolean) => void` | — | Called when open state changes |
| `modal` | `boolean` | `true` | When true, interaction outside the sheet is blocked |

### SheetContent

| Prop | Type | Default | Description |
|---|---|---|---|
| `side` | `'top' \| 'right' \| 'bottom' \| 'left'` | `'right'` | Edge the sheet slides in from |
| `size` | `'sm' \| 'default' \| 'lg' \| 'xl' \| 'full'` | `'default'` | Width of a left or right sheet (ignored for top/bottom) |
| `className` | `string` | — | Merged with the panel class list |

## Sub-components

| Component | Description |
|---|---|
| `SheetTrigger` | Opens the sheet |
| `SheetClose` | Closes the sheet — also rendered as an × button inside `SheetContent` |
| `SheetHeader` | Top section with bottom border — wrap `SheetTitle` and `SheetDescription` here |
| `SheetBody` | Scrollable middle section with padding |
| `SheetFooter` | Bottom section with top border — for action buttons |
| `SheetTitle` | Accessible title (required for screen readers) |
| `SheetDescription` | Accessible description |

## Accessibility

- Focus is trapped inside the sheet while it is open
- `Escape` closes the sheet
- The backdrop click closes the sheet
- `SheetTitle` maps to `aria-labelledby` on the panel; `SheetDescription` to `aria-describedby`
- The built-in × button has a visually hidden "Close" label for screen readers
