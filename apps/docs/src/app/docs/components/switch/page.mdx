## With icons

## Custom color

Override the checked color by passing a Tailwind arbitrary value via `className`. The unchecked track color (`bg-foreground/20`) adapts automatically to both themes. To recolor the thumb (knob), use `thumbClassName` — it accepts `data-[state=checked]:` variants too.

<Showcase title="Custom color" code={`{/* Success */}
<Switch className="data-[state=checked]:bg-[oklch(0.65_0.19_145)]" defaultChecked />

{/* Warning */}
<Switch className="data-[state=checked]:bg-[oklch(0.72_0.18_75)]" defaultChecked />

{/* Danger */}
<Switch className="data-[state=checked]:bg-[oklch(0.63_0.22_29)]" defaultChecked />

{/* Rose */}
<Switch className="data-[state=checked]:bg-[oklch(0.65_0.21_10)]" defaultChecked />`}>
  <SwitchCustomColorPreview />
</Showcase>

## API

### Switch

| Prop | Type | Default | Description |
|---|---|---|---|
| `size` | `'sm' \| 'default' \| 'lg'` | `'default'` | Controls track and thumb dimensions |
| `checked` | `boolean` | — | Controlled checked state |
| `defaultChecked` | `boolean` | `false` | Uncontrolled initial state |
| `onCheckedChange` | `(checked: boolean) => void` | — | Called when state changes |
| `disabled` | `boolean` | `false` | Prevents interaction |
| `required` | `boolean` | `false` | Marks the input as required in a form |
| `name` | `string` | — | Input name for form submission |
| `value` | `string` | `'on'` | Value submitted in a form when checked |
| `className` | `string` | — | Additional class names — use `data-[state=checked]:bg-[...]` to override the active color |
| `thumbClassName` | `string` | — | Styles the thumb (knob) — e.g. `bg-card data-[state=checked]:bg-[...]` to color it per state |

## Accessibility

- Rendered as `<button role="switch">` — toggled with `Space` or `Enter`
- `aria-checked` reflects the current on/off state
- Connect a visible `<label>` using `htmlFor` matching the switch `id`
- Disabled switches use `aria-disabled="true"` and are excluded from tab order
- Prefer Switch over Checkbox when the change takes effect immediately (no form submit)
