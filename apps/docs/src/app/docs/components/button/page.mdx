## Usage

### Basic

#### Solid

The primary call-to-action. Use once per region — never stack multiple solid buttons side by side.

<Showcase title="Solid" code={`<Button>Button</Button>\n<Button disabled>Disabled</Button>`}>
  <BtnSolidPreview />
</Showcase>

#### Text

No background or border — lowest visual weight. Good for tertiary actions inside dense layouts.

<Showcase title="Text" code={`<Button variant="text">Button</Button>\n<Button variant="text" disabled>Disabled</Button>`}>
  <BtnTextPreview />
</Showcase>

#### Soft

Tinted background at low opacity — sits between solid and ghost in emphasis.

<Showcase title="Soft" code={`<Button variant="soft">Button</Button>\n<Button variant="soft" disabled>Disabled</Button>`}>
  <BtnSoftPreview />
</Showcase>

#### Outlined

Border with transparent background. Use as a secondary action paired with a solid primary.

<Showcase title="Outlined" code={`<Button variant="outline">Button</Button>\n<Button variant="outline" disabled>Disabled</Button>`}>
  <BtnOutlinePreview />
</Showcase>

#### Dash

Dashed border — signals a placeholder or additive action like "Add block" or "Upload file".

<Showcase title="Dash" code={`<Button variant="dash">Button</Button>\n<Button variant="dash" disabled>Disabled</Button>`}>
  <BtnDashPreview />
</Showcase>

#### Ghost

No background, no border at rest. Hover reveals a muted fill. Use for toolbar actions and nav items.

<Showcase title="Ghost" code={`<Button variant="ghost">Button</Button>\n<Button variant="ghost" disabled>Disabled</Button>`}>
  <BtnGhostPreview />
</Showcase>

#### Link

Looks like an anchor tag. Use for inline navigation inside prose or form copy.

<Showcase title="Link" code={`<Button variant="link">Button</Button>\n<Button variant="link" disabled>Disabled</Button>`}>
  <BtnLinkPreview />
</Showcase>

#### Icon

Square button for icon-only actions. Always provide an `aria-label`.

<Showcase title="Icon" code={`<Button size="icon" aria-label="Add">\n  <PlusIcon />\n</Button>`}>
  <BtnIconVariantsPreview />
</Showcase>

### Icon

#### Icon only

Three sizes — match the size of adjacent inputs and controls.

<Showcase title="Icon only" code={`{/* sm */}\n<Button size="icon" aria-label="Add" style={{ height: 36, width: 36 }}>\n  <PlusIcon />\n</Button>\n\n{/* default */}\n<Button size="icon" aria-label="Add">\n  <PlusIcon />\n</Button>\n\n{/* lg */}\n<Button size="icon" aria-label="Add" style={{ height: 44, width: 44 }}>\n  <PlusIcon />\n</Button>`}>
  <BtnIconOnlyPreview />
</Showcase>

#### With icon

Icons are 14 px and inherit the text color. Mark them `aria-hidden` — the label carries the accessible name.

<Showcase title="With icon" code={`{/* leading */}\n<Button><PlusIcon />New project</Button>\n<Button variant="secondary"><DownloadIcon />Download</Button>\n\n{/* trailing */}\n<Button>Continue <ArrowIcon /></Button>`}>
  <BtnWithIconPreview />
</Showcase>

### Button group

Wrap two or more Buttons in `.btn-group` for a connected segmented control.

#### Solid

</Showcase>

#### Soft

<Showcase title="Soft group" code={`<div className="btn-group">\n  <Button variant="soft">Day</Button>\n  <Button variant="soft">Week</Button>\n  <Button variant="soft">Month</Button>\n</div>`}>
  <BtnGroupSoftPreview />
</Showcase>

#### Outlined

<Showcase title="Outlined group" code={`<div className="btn-group">\n  <Button variant="outline">Day</Button>\n  <Button variant="outline">Week</Button>\n  <Button variant="outline">Month</Button>\n</div>`}>

</Showcase>

### Borders

#### Rounded

Default shape — `border-radius` inherits from `--radius`.

<Showcase title="Rounded" code={`<Button>Default</Button>\n<Button variant="outline">Outlined</Button>\n<Button variant="secondary">Secondary</Button>`}>
  <BtnBorderRoundedPreview />
</Showcase>

#### Box

Sharp corners — zero border-radius. Useful in dense data UIs and toolbars.

<Showcase title="Box" code={`<Button style={{ borderRadius: 0 }}>Default</Button>\n<Button variant="outline" style={{ borderRadius: 0 }}>Outlined</Button>`}>
  <BtnBorderBoxPreview />
</Showcase>

#### Dashed

Dashed outline — signals an additive or placeholder action.

<Showcase title="Dashed" code={`<Button variant="dash">Default</Button>\n<Button variant="dash" color="primary">Primary</Button>`}>
  <BtnBorderDashedPreview />
</Showcase>

### Loading

Set `disabled` and `aria-busy="true"` while an async action is in flight. Use a `.btn-spinner` inside the button paired with an in-progress label.

<Showcase title="Loading" code={`<Button disabled aria-busy="true">\n  <span className="btn-spinner" aria-hidden="true" />\n  Saving…\n</Button>`}>
  <BtnLoadingPreview />
</Showcase>
