## Variants

Five visual styles that control shape and fill. Combine with `color` for semantic meaning.

### Solid

The primary call-to-action. Use once per region — never stack multiple solid buttons side by side.

<Showcase title="Solid" code={`<Button>Save changes</Button>`}>
  <BtnSolidPreview />
</Showcase>

### Soft

Tinted background at low opacity — sits between solid and ghost in emphasis.

<Showcase title="Soft" code={`<Button variant="soft">Save changes</Button>`}>
  <BtnSoftPreview />
</Showcase>

### Outline

Border with transparent background. Use as a secondary action paired with a solid primary.

<Showcase title="Outline" code={`<Button variant="outline">Learn more</Button>`}>
  <BtnOutlinePreview />
</Showcase>

### Ghost

No background, no border at rest. Hover reveals a muted fill. Use for toolbar actions and nav items.

<Showcase title="Ghost" code={`<Button variant="ghost">Skip for now</Button>`}>
  <BtnGhostPreview />
</Showcase>

### Link

Looks like an anchor tag. Use for inline navigation inside prose or form copy.

<Showcase title="Link" code={`<Button variant="link">View documentation</Button>`}>
  <BtnLinkPreview />
</Showcase>

## States

Every button passes through these states. Disabled reduces opacity to 50% and removes pointer events — use `aria-disabled` instead when you need the button to remain focusable.

## With icons

Icons are 14 px and inherit the text color. Mark decorative icons `aria-hidden` — the button label carries the accessible name.

### Icon only

Use `size="icon"` for square icon-only buttons. Always provide an `aria-label`. Match the size to adjacent inputs and controls.

<Showcase title="Icon only" code={`import { Plus } from 'lucide-react'\nimport { Button } from '@tokiui/ui'\n\n{/* sm */}\n<Button variant="outline" color="neutral" size="icon" aria-label="Add" className="size-9">\n  <Plus />\n</Button>\n\n{/* default */}\n<Button variant="outline" color="neutral" size="icon" aria-label="Add">\n  <Plus />\n</Button>\n\n{/* lg */}\n<Button variant="outline" color="neutral" size="icon" aria-label="Add" className="size-11">\n  <Plus />\n</Button>`}>
  <BtnIconOnlyPreview />
</Showcase>

### Leading & trailing

Place icons before the label for actions (New, Download), after for direction (Continue, Read more).

<Showcase title="With icon" code={`import { Plus, Download, Copy, Trash2, ArrowRight, ExternalLink } from 'lucide-react'\nimport { Button } from '@tokiui/ui'\n\n{/* leading icon */}\n<Button><Plus />New project</Button>\n<Button color="neutral"><Download />Download</Button>\n<Button variant="outline"><Copy />Copy link</Button>\n<Button variant="ghost"><Trash2 />Remove</Button>\n\n{/* trailing icon */}\n<Button>Continue <ArrowRight /></Button>\n<Button variant="ghost">Read more <ExternalLink /></Button>`}>

## Color

The `color` prop applies semantic meaning across any variant. Use `variant` to pick the shape, `color` to signal the intent.

### Primary

The default. Use for the main call-to-action — one per region.

<Showcase title="Primary" code={`<Button>Button</Button>\n<Button variant="soft">Soft</Button>\n<Button variant="outline">Outline</Button>\n<Button variant="ghost">Ghost</Button>`}>
  <BtnColorPrimaryPreview />
</Showcase>

### Neutral

For secondary or cancel actions that carry no semantic weight.

<Showcase title="Neutral" code={`<Button color="neutral">Button</Button>\n<Button variant="soft" color="neutral">Soft</Button>\n<Button variant="outline" color="neutral">Outline</Button>\n<Button variant="ghost" color="neutral">Ghost</Button>`}>

</Showcase>

### Destructive

For irreversible actions only — deleting data, leaving a team, cancelling a subscription.

## Full width

Add `className="w-full"` to make a button fill its container. No new variant needed — it composes with any existing variant and color.

### Stacked

Common in mobile forms and onboarding flows where each action gets its own row.

<Showcase title="Stacked" code={`<div className="flex flex-col gap-3 w-full max-w-xs">\n  <Button className="w-full">Create account</Button>\n  <Button variant="outline" className="w-full">Sign in instead</Button>\n</div>`}>
  <BtnFullWidthStackedPreview />
</Showcase>

### Side by side

Common in dialog footers and card actions where cancel and confirm sit in the same row with equal weight.

<Showcase title="Side by side" code={`<div className="flex gap-2 w-full max-w-xs">\n  <Button variant="outline" color="neutral" className="w-full">Cancel</Button>\n  <Button className="w-full">Save changes</Button>\n</div>`}>
  <BtnFullWidthRowPreview />
</Showcase>

## Loading
