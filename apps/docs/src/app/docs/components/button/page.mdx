# Button

Displays a button. Supports six variants, three sizes, and `asChild` for rendering as any element.

## Usage

```tsx
import { Button } from '@/components/ui/button'

<Button>Click me</Button>
```

## Props

| Prop | Type | Default |
|---|---|---|
| `variant` | `default \| destructive \| outline \| secondary \| ghost \| link` | `default` |
| `size` | `default \| sm \| lg \| icon` | `default` |
| `asChild` | `boolean` | `false` |
| `disabled` | `boolean` | `false` |

When `asChild` is `true`, the button renders as its child element using Radix Slot — useful for rendering a `<Link>` that looks like a button.
