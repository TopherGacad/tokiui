## Basic

Wrap your layout in `SidebarProvider`. The `Sidebar` and `SidebarInset` sit inside as flex siblings — the sidebar transitions its width and the inset takes the remaining space. `SidebarTrigger` in the topbar toggles collapse.

<Showcase title="Basic" code={`<SidebarProvider defaultOpen>\n  <Sidebar>\n    <SidebarHeader>...</SidebarHeader>\n    <SidebarContent>\n      <SidebarGroup>\n        <SidebarGroupLabel>Main</SidebarGroupLabel>\n        <SidebarMenu>\n          <SidebarMenuItem>\n            <SidebarMenuButton isActive tooltip="Dashboard">\n              <HomeIcon />\n              <span>Dashboard</span>\n              <SidebarMenuBadge>12</SidebarMenuBadge>\n            </SidebarMenuButton>\n          </SidebarMenuItem>\n        </SidebarMenu>\n      </SidebarGroup>\n    </SidebarContent>\n    <SidebarFooter>...</SidebarFooter>\n  </Sidebar>\n\n  <SidebarInset>\n    <header>\n      <SidebarTrigger />\n    </header>\n    {/* page content */}\n  </SidebarInset>\n</SidebarProvider>`}>

</Showcase>

## Collapsible sub-menus

Nest a `SidebarMenuSub` inside a `SidebarMenuItem` for expandable sections. A parent `SidebarMenuButton` toggles local open state and rotates a chevron; `SidebarMenuSub` renders an indented, guide-lined list of `SidebarMenuSubButton` links and hides itself automatically when the rail is in icon mode.

<Showcase title="Sub-menus" code={`function NavItem({ icon: Icon, label, items }) {\n  const [open, setOpen] = React.useState(false)\n  return (\n    <SidebarMenuItem>\n      <SidebarMenuButton onClick={() => setOpen(!open)} aria-expanded={open}>\n        <Icon />\n        <span>{label}</span>\n        <ChevronRight className={cn('ml-auto transition-transform', open && 'rotate-90')} />\n      </SidebarMenuButton>\n      {open && (\n        <SidebarMenuSub>\n          {items.map((item) => (\n            <SidebarMenuSubItem key={item.label}>\n              <SidebarMenuSubButton asChild isActive={item.active}>\n                <a href={item.href}>{item.label}</a>\n              </SidebarMenuSubButton>\n            </SidebarMenuSubItem>\n          ))}\n        </SidebarMenuSub>\n      )}\n    </SidebarMenuItem>\n  )\n}`}>
  <SidebarSubmenuPreview />
</Showcase>

## Icon rail

Start collapsed with `defaultOpen={false}`. In collapsed mode each `SidebarMenuButton` with a `tooltip` prop shows a side-anchored tooltip on hover. The trigger in the topbar expands to full width.

<Showcase title="Icon rail" code={`<SidebarProvider defaultOpen={false}>\n  <Sidebar>\n    <SidebarContent>\n      <SidebarMenu>\n        {items.map(({ label, icon: Icon }) => (\n          <SidebarMenuItem key={label}>\n            <SidebarMenuButton tooltip={label} isActive={active === label}>\n              <Icon />\n              <span>{label}</span>\n            </SidebarMenuButton>\n          </SidebarMenuItem>\n        ))}\n      </SidebarMenu>\n    </SidebarContent>\n  </Sidebar>\n  <SidebarInset>...</SidebarInset>\n</SidebarProvider>`}>

## API

### SidebarProvider

| Prop | Type | Default | Description |
|---|---|---|---|
| `defaultOpen` | `boolean` | `true` | Initial open state (uncontrolled) |
| `open` | `boolean` | — | Controlled open state |
| `onOpenChange` | `(open: boolean) => void` | — | Called when open state changes |

### useSidebar

```tsx
const { open, setOpen, toggle } = useSidebar()
```

Access sidebar state from any child without prop drilling.

### Sidebar

| Prop | Type | Default | Description |
|---|---|---|---|
| `side` | `left \| right` | `left` | Which side the sidebar is on |

### SidebarMenuButton

| Prop | Type | Default | Description |
|---|---|---|---|
| `isActive` | `boolean` | `false` | Applies active highlight — `bg-primary/10 text-primary` |
| `tooltip` | `string` | — | Label shown as a right-anchored tooltip when the sidebar is collapsed |
| `asChild` | `boolean` | `false` | Renders the child element instead of `<button>` — use with `<Link>` |

### SidebarMenuBadge

Inline count badge that fades out when the sidebar is collapsed. Place it as the last child inside `SidebarMenuButton`.

### SidebarMenuSub

Nested sub-menu primitives for expandable navigation — place a `SidebarMenuSub` inside a `SidebarMenuItem`, right after the parent `SidebarMenuButton`. It renders an indented list with a vertical guide and hides automatically in the collapsed icon rail.

| Component | Element | Props |
|---|---|---|
| `SidebarMenuSub` | `<ul>` | — |
| `SidebarMenuSubItem` | `<li>` | — |
| `SidebarMenuSubButton` | `<a>` | `asChild`, `isActive` |

### SidebarInset

The main content wrapper that sits beside the sidebar in the flex layout. Takes `flex-1` and handles its own overflow.

## Accessibility

- `SidebarTrigger` has `aria-label` that updates between "Collapse sidebar" and "Expand sidebar"
- Collapsed icon-only buttons include `tooltip` text as a visible label for sighted keyboard and pointer users
- Navigation landmarks: wrap `Sidebar` in a `<nav aria-label="Main navigation">` for screen readers
