## Pill variant

A compact segmented control for toggling between a small set of options — common for date range selectors and view modes.

<Showcase title="Pill variant" code={`const ranges = ['Day', 'Week', 'Month', 'Year']

## API

### Tabs

| Prop | Type | Default | Description |
|---|---|---|---|
| `value` | `string` | — | Controlled active tab |
| `defaultValue` | `string` | — | Uncontrolled initial active tab |
| `onValueChange` | `(value: string) => void` | — | Called when active tab changes |
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | Affects arrow key navigation direction |
| `activationMode` | `'automatic' \| 'manual'` | `'automatic'` | `automatic` activates on focus; `manual` requires Enter/Space |

### TabsTrigger

| Prop | Type | Default | Description |
|---|---|---|---|
| `value` | `string` | **required** | The tab this trigger activates |
| `disabled` | `boolean` | `false` | Prevents selection |

### TabsContent

| Prop | Type | Default | Description |
|---|---|---|---|
| `value` | `string` | **required** | Matches the trigger `value` this panel belongs to |
| `forceMount` | `boolean` | — | Keep content mounted even when inactive — useful for animations |

## Accessibility

- Arrow keys (`←` `→` or `↑` `↓`) move between tabs
- `TabsList` has `role="tablist"`, each trigger has `role="tab"` with `aria-selected`
- Active panel has `role="tabpanel"` and is linked to its trigger via `aria-controls` / `aria-labelledby`
- Disabled triggers have `aria-disabled="true"` and are skipped during keyboard navigation
