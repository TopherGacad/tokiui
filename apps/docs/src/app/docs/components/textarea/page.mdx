## Character count

Track remaining characters with a controlled textarea and `maxLength`.

<Showcase title="Character count" code={`'use client'
import { useState } from 'react'

const MAX = 280

export function PostInput() {
  const [value, setValue] = useState('')
  const remaining = MAX - value.length

  return (
    <div style={{ display: 'grid', gap: 6 }}>
      <Textarea
        placeholder="What's on your mind?"
        rows={4}
        maxLength={MAX}
        value={value}
        onChange={(e) => setValue(e.target.value)}
      />
      <div style={{ display: 'flex', justifyContent: 'flex-end' }}>
        <span style={{
          fontSize: 12,
          color: remaining <= 20 ? 'var(--destructive)' : 'var(--muted-foreground)',
        }}>
          {remaining}/{MAX}
        </span>
      </div>
    </div>
  )
}`}>
  <TextareaCharCountPreview />
</Showcase>

## API

### Textarea

| Prop | Type | Default | Description |
|---|---|---|---|
| `size` | `sm \| default \| lg` | `default` | Field height and text size |
| `error` | `boolean` | `false` | Applies destructive border and ring |
| `showCount` | `boolean` | `false` | Shows a live character count below the field |
| `maxLength` | `number` | — | Caps input length; shows `n / max` counter when set |
| `autoResize` | `boolean` | `false` | Grows the field height to fit content as the user types |
| `rows` | `number` | — | Initial number of visible text rows |
| `placeholder` | `string` | — | Placeholder text when the field is empty |
| `disabled` | `boolean` | `false` | Prevents interaction |
| `value` | `string` | — | Controlled value |
| `defaultValue` | `string` | — | Uncontrolled initial value |
| `onChange` | `React.ChangeEventHandler` | — | Called on every keystroke |
| `className` | `string` | — | Additional class names |

## Accessibility

- Use `<label>` with `htmlFor` matching the textarea `id`
- Set `aria-invalid="true"` on the textarea when it has a validation error
- Connect the error message with `aria-describedby` pointing to the error element's `id`
- Disabled textareas have `aria-disabled="true"` implicitly via the `disabled` attribute
