## Dismissable

Pass `onDismiss` to show a × button in the top-right corner. Wire it to your state to remove the alert.

<Showcase title="Dismissable" code={`'use client'
import { useState } from 'react'

export function DismissableAlerts() {
  const [visible, setVisible] = useState(true)

  if (!visible) return null

  return (
    <Alert
      variant="success"
      title="Deployment complete"
      onDismiss={() => setVisible(false)}
    >
      Your changes are live on production.
    </Alert>
  )
}`}>
  <AlertDismissPreview />
</Showcase>

## Custom icon

Pass any JSX to `icon` to replace the default icon. Pass `null` to suppress it entirely.

<Showcase title="Custom icon" code={`<Alert variant="info" title="New feature available" icon={<RocketIcon />}>
  Press ⌘K to open the command palette.
</Alert>

{/* No icon */}
<Alert variant="default" title="No icon" icon={null}>
  The icon prop accepts null to suppress the default icon.
</Alert>`}>
  <AlertCustomIconPreview />
</Showcase>

## API

### Alert

| Prop | Type | Default | Description |
|---|---|---|---|
| `variant` | `'default' \| 'success' \| 'warning' \| 'info' \| 'destructive'` | `'default'` | Color scheme and default icon |
| `title` | `ReactNode` | — | Bold heading rendered above the body |
| `icon` | `ReactNode` | auto | Custom icon — pass `null` to suppress the default |
| `onDismiss` | `() => void` | — | Shows a × button; called when clicked |
| `className` | `string` | — | Additional class names |
| `children` | `ReactNode` | — | Body text |

## Accessibility

- `role="alert"` is set on the root element so screen readers announce the content immediately
- The dismiss button has `aria-label="Dismiss"` for screen readers
- Icons are `aria-hidden="true"` — they are decorative and do not add information
- Pair with `aria-live="polite"` on a container if you are inserting alerts dynamically
