## Checkbox items

`DropdownMenuCheckboxItem` shows a checkmark indicator when `checked`. Use it for toggling view options and persistent settings.

<Showcase title="Checkbox items" code={`'use client'
import { useState } from 'react'

export function ViewMenu() {
  const [state, setState] = useState({ statusBar: true, activityBar: true, panel: false })

  return (
    <DropdownMenu>
      <DropdownMenuTrigger asChild><button>View</button></DropdownMenuTrigger>
      <DropdownMenuContent className="w-48">
        <DropdownMenuLabel>Appearance</DropdownMenuLabel>
        <DropdownMenuSeparator />
        <DropdownMenuCheckboxItem
          checked={state.statusBar}
          onCheckedChange={(v) => setState(p => ({ ...p, statusBar: v }))}
        >
          Status Bar
        </DropdownMenuCheckboxItem>
        <DropdownMenuCheckboxItem
          checked={state.panel}
          onCheckedChange={(v) => setState(p => ({ ...p, panel: v }))}
        >
          Panel
        </DropdownMenuCheckboxItem>
      </DropdownMenuContent>
    </DropdownMenu>
  )
}`}>
  <DropdownMenuCheckboxPreview />
</Showcase>

## API

### DropdownMenu

| Prop | Type | Default | Description |
|---|---|---|---|
| `open` | `boolean` | — | Controlled open state |
| `defaultOpen` | `boolean` | `false` | Uncontrolled initial open state |
| `onOpenChange` | `(open: boolean) => void` | — | Called when open state changes |
| `modal` | `boolean` | `true` | When true, interaction outside the menu is blocked |

### DropdownMenuContent

| Prop | Type | Default | Description |
|---|---|---|---|
| `side` | `'top' \| 'right' \| 'bottom' \| 'left'` | `'bottom'` | Preferred side to open |
| `sideOffset` | `number` | `6` | Distance from trigger in px |
| `align` | `'start' \| 'center' \| 'end'` | `'center'` | Alignment along the side |
| `className` | `string` | — | Use `w-[...]` to set a fixed menu width |

### DropdownMenuItem

| Prop | Type | Default | Description |
|---|---|---|---|
| `icon` | `ReactNode` | — | Icon rendered before the label in a muted color |
| `description` | `string` | — | Secondary text rendered below the label |
| `disabled` | `boolean` | `false` | Prevents selection |
| `onSelect` | `(event: Event) => void` | — | Called when the item is selected |
| `inset` | `boolean` | `false` | Adds left padding to align with icon items |

### DropdownMenuSubTrigger

| Prop | Type | Default | Description |
|---|---|---|---|
| `icon` | `ReactNode` | — | Icon rendered before the label |
| `inset` | `boolean` | `false` | Adds left padding to align with icon items |

## Sub-components

| Component | Description |
|---|---|
| `DropdownMenuLabel` | Non-interactive section heading |
| `DropdownMenuSeparator` | Horizontal divider |
| `DropdownMenuShortcut` | Right-aligned keyboard shortcut text |
| `DropdownMenuGroup` | Groups items together logically |
| `DropdownMenuCheckboxItem` | Item with a toggleable checkmark |
| `DropdownMenuRadioGroup` | Container for mutually exclusive radio items |
| `DropdownMenuRadioItem` | Single radio option within a group |
| `DropdownMenuSub` | Root for a nested submenu |
| `DropdownMenuSubTrigger` | Item that opens a submenu on hover/focus |
| `DropdownMenuSubContent` | The submenu panel |

## Accessibility

- Opens with `Enter`, `Space`, or `ArrowDown` on the trigger
- Arrow keys navigate between items; `Escape` closes the menu
- `DropdownMenuContent` has `role="menu"`; each item has `role="menuitem"`
- Disabled items have `aria-disabled="true"` and are skipped during keyboard navigation
- Checkbox items use `role="menuitemcheckbox"`; radio items use `role="menuitemradio"`
