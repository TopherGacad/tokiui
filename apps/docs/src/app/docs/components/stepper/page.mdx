## Import

```tsx
import {
  Stepper,
  StepperItem,
  StepperIndicator,
  StepperContent,
  StepperTitle,
  StepperDescription,
  StepperSeparator,
} from '@tokiui/ui'
```

## Basic

Pass `step` to `Stepper` for the currently active step (1-indexed). Each `StepperItem` derives its status automatically — complete, active, or incomplete.

<Showcase title="Basic" code={`const [step, setStep] = React.useState(1)\n\n<Stepper step={step} className="w-full">\n  {STEPS.map((s, i) => (\n    <React.Fragment key={s.title}>\n      <StepperItem step={i + 1}>\n        <StepperIndicator />\n        <StepperContent>\n          <StepperTitle>{s.title}</StepperTitle>\n          <StepperDescription>{s.description}</StepperDescription>\n        </StepperContent>\n      </StepperItem>\n      {i < STEPS.length - 1 && <StepperSeparator />}\n    </React.Fragment>\n  ))}\n</Stepper>`}>
  <StepperBasicPreview />
</Showcase>

## API

### Stepper

| Prop | Type | Default | Description |
|---|---|---|---|
| `step` | `number` | — | The currently active step (1-indexed) |
| `orientation` | `horizontal \| vertical` | `horizontal` | Layout direction |

### StepperItem

| Prop | Type | Default | Description |
|---|---|---|---|
| `step` | `number` | — | This item's step number — used to compute complete / active / incomplete status |

### StepperIndicator

| Prop | Type | Default | Description |
|---|---|---|---|
| `icon` | `ReactNode` | — | Custom icon shown for incomplete and active states. Completed steps always show a checkmark. |

### StepperSeparator

Renders a connecting line between two steps. Place it between `StepperItem` elements — omit it after the last step. Orientation and fill color are derived from context automatically.

### StepperContent / StepperTitle / StepperDescription

Presentational wrappers. `StepperTitle` and `StepperDescription` automatically adjust their text color based on the parent step's status.

## Accessibility

- Wrap a `Stepper` in a `<nav aria-label="Progress">` when it doubles as navigation
- Mark the active step with `aria-current="step"` on the clickable trigger if steps are interactive
- Use `aria-disabled` on `StepperItem` for locked steps
