## Default

`type="single"` allows only one item open at a time. Add `collapsible` to let the open item close when clicked again.

</Showcase>

## Multiple

`type="multiple"` lets any number of items be open simultaneously. Useful for FAQs where users may want to compare answers.

<Showcase title="Multiple" code={`<Accordion type="multiple">\n  <AccordionItem value="item-1">\n    <AccordionTrigger>Shipping & delivery</AccordionTrigger>\n    <AccordionContent>Standard shipping takes 3–5 business days.</AccordionContent>\n  </AccordionItem>\n</Accordion>`}>
  <AccordionMultiplePreview />
</Showcase>

## Variants

### Separated

Each item is an independent card. Use in settings pages or anywhere visual separation between items matters.

<Showcase title="Separated" code={`<Accordion type="single" collapsible variant="separated">\n  <AccordionItem value="item-1">\n    <AccordionTrigger>How does billing work?</AccordionTrigger>\n    <AccordionContent>You are billed monthly on the date you first subscribed.</AccordionContent>\n  </AccordionItem>\n</Accordion>`}>
  <AccordionSeparatedPreview />
</Showcase>

### Flush

No outer border — only dividers between items. Fits naturally inside an existing card or sidebar panel.

<Showcase title="Flush" code={`<Accordion type="single" collapsible variant="flush">\n  <AccordionItem value="item-1">\n    <AccordionTrigger>General settings</AccordionTrigger>\n    <AccordionContent>Update your display name, language preference, and timezone.</AccordionContent>\n  </AccordionItem>\n</Accordion>`}>
  <AccordionFlushPreview />
</Showcase>

## With badge

Combine `AccordionTrigger` with `Badge` to add category tags or status indicators to each item.

<Showcase title="FAQ with tags" code={`<AccordionTrigger>\n  <span className="flex items-center gap-2.5">\n    <Badge variant="soft" color="info" size="sm">Updates</Badge>\n    How do I update a component?\n  </span>\n</AccordionTrigger>`}>

## API

### Accordion

| Prop | Type | Default | Description |
|---|---|---|---|
| `type` | `single \| multiple` | **required** | Whether one or many items can be open |
| `variant` | `default \| separated \| flush` | `default` | Visual style |
| `collapsible` | `boolean` | `false` | When `type="single"`, allows closing the open item |
| `value` | `string \| string[]` | — | Controlled open item(s) |
| `defaultValue` | `string \| string[]` | — | Uncontrolled initial open item(s) |
| `onValueChange` | `(value) => void` | — | Called when open state changes |
| `disabled` | `boolean` | `false` | Disables all items |

### AccordionItem

| Prop | Type | Default | Description |
|---|---|---|---|
| `value` | `string` | **required** | Unique identifier for this item |
| `disabled` | `boolean` | `false` | Disables this specific item |

### AccordionTrigger

Accepts all standard `<button>` HTML attributes. Children become the trigger label.

### AccordionContent

Accepts all standard `<div>` HTML attributes. Children are wrapped in a padded container.

## Accessibility

- Built on Radix UI — fully WAI-ARIA compliant
- `Space` / `Enter` toggles the focused item
- `Tab` moves focus between triggers
- `Home` / `End` jump to first / last trigger
- Each trigger has `aria-expanded` and `aria-controls` wired automatically
