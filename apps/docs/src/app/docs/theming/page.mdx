# Theming

tokiui uses CSS custom properties for all colors and border radius. Change the entire look of your app by overriding a few variables in your `globals.css` — no component changes required.

## How it works

All components use semantic Tailwind classes like `bg-primary` and `text-muted-foreground`. These classes are wired to CSS variables via the `@theme` block inside `@tokiui/ui/styles.css`:

```css
@theme {
  --color-primary: var(--primary);
  --color-muted-foreground: var(--muted-foreground);
  /* ... */
}
```

The actual values live in `:root` (light) and `[data-theme="dark"]` (dark mode). tokiui uses the **OKLCH color space** — a perceptually uniform model where equal steps in lightness or chroma look equal to the human eye, making it easier to build consistent palettes.

```css
:root {
  --primary: oklch(0.52 0.16 145);
}
[data-theme="dark"] {
  --primary: oklch(0.72 0.15 145);
}
```

### Radius tokens

Changing `--radius` shifts all derived sizes proportionally:

| Token | Formula | Default |
|---|---|---|
| `--radius-sm` | `calc(var(--radius) - 4px)` | `6px` |
| `--radius-md` | `calc(var(--radius) - 2px)` | `8px` |
| `--radius-lg` | `var(--radius)` | `10px` |
| `--radius-xl` | `calc(var(--radius) + 4px)` | `14px` |

## Customizing your theme

Override any variable in your `globals.css` after the import:

```css
@import "tailwindcss";
@import "@tokiui/ui/styles.css";

:root {
  --primary: oklch(0.55 0.22 270);  /* purple */
  --ring:    oklch(0.55 0.22 270);
  --radius:  14px;                   /* rounder corners */
}

[data-theme="dark"] {
  --primary: oklch(0.72 0.20 270);
}
```

<Callout>
Override both `:root` and `[data-theme="dark"]` when changing color tokens — the dark value usually needs a higher lightness to maintain contrast.
</Callout>

## Preset themes

Prefer to start from a ready-made palette? `@tokiui/themes` ships five, each a complete light + dark set of OKLCH tokens:

| Preset | Character |
|---|---|
| `default` | The neutral, green-tinted palette shipped in `@tokiui/ui/styles.css` |
| `rose` | Warm, higher-contrast rose primary |
| `slate` | Cool, desaturated slate neutrals |
| `neon` | Vivid violet primary with a mint accent and rounded corners |
| `newspaper` | Near-monochrome, ink-on-paper with tight radii |

A preset is just a set of token values, so you apply one exactly the way you customize your own theme — set the variables in `globals.css`. For example, `neon`:

```css
:root {
  --primary: oklch(0.52 0.32 295);
  --accent:  oklch(0.81 0.22 162);
  --ring:    oklch(0.52 0.32 295);
  --radius:  0.75rem;
}
[data-theme="dark"] {
  --primary: oklch(0.65 0.30 295);
  --accent:  oklch(0.85 0.24 162);
}
```

The quickest way to get every value is the [playground](/playground) — select a preset and copy the full token set.

## Designing a theme in the playground

The [playground](/playground) is a live editor for all tokens, with light and dark side by side and real components to preview against. Pick one of the five presets to start, or tune from scratch, then use the toolbar:

- **Copy CLI command** — copies `npx @tokiui/cli theme apply <token>`. Run it at your project root and the CLI writes your light + dark tokens into `globals.css` (inside `/* tokiui theme */` markers, so re-running replaces the block cleanly). The fastest way to move a playground theme into a real app.
- **Copy CSS variables** — copies a complete `:root { … }` and `[data-theme="dark"] { … }` block. Paste it into `globals.css` **after** the tokiui import and it overrides the defaults wholesale.
- **Copy theme URL** — copies a shareable link that reopens the playground with your exact tokens.

```css
@import "tailwindcss";
@import "@tokiui/ui/styles.css";

/* paste your copied blocks below — they win because they come after the import */
:root { /* … */ }
[data-theme="dark"] { /* … */ }
```

<Callout>
The playground emits the full token set, so pasting a copied block replaces the theme wholesale rather than patching individual values. Keep it **after** the `@tokiui/ui/styles.css` import.
</Callout>

## Dark mode

Dark mode is driven by the `data-theme="dark"` attribute on the `<html>` element:

```ts
document.documentElement.dataset.theme = 'dark'
document.documentElement.dataset.theme = 'light'
```

### useTheme hook

Use the `useTheme` hook from `@tokiui/ui/client` for a `localStorage`-persisted toggle that also reads the system preference on first load:

```tsx
'use client'
import { useTheme } from '@tokiui/ui/client'

export function ThemeToggle() {
  const [theme, toggle] = useTheme()
  return <button onClick={toggle}>Switch to {theme === 'dark' ? 'light' : 'dark'}</button>
}
```

Pass `{ transition: true }` to animate the switch as a full-page crossfade via the [View Transitions API](https://developer.mozilla.org/en-US/docs/Web/API/View_Transitions_API). It falls back to an instant switch where unsupported, and tokiui ships the default crossfade timing in `styles.css`:

```tsx
const [theme, toggle] = useTheme({ transition: true })
```

### Preventing flash of unstyled content

In SSR frameworks (Next.js, Remix) the page renders on the server before JavaScript runs, so there's a brief flash where dark mode isn't applied. Fix this by adding a blocking inline script to your HTML `<head>` that reads `localStorage` and sets the attribute before first paint.

**Next.js App Router** — add to `app/layout.tsx`:

```tsx
const themeScript = `(function() {
  try {
    var stored = localStorage.getItem('tokiui-theme')
    var preferred = window.matchMedia('(prefers-color-scheme: dark)').matches
      ? 'dark' : 'light'
    document.documentElement.dataset.theme = stored || preferred
  } catch(e) {}
})()`

export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <head>
        <script dangerouslySetInnerHTML={{ __html: themeScript }} />
      </head>
      <body>{children}</body>
    </html>
  )
}
```

**Remix** — add to `app/root.tsx`:

```tsx
const themeScript = `(function() {
  try {
    var stored = localStorage.getItem('tokiui-theme')
    var preferred = window.matchMedia('(prefers-color-scheme: dark)').matches
      ? 'dark' : 'light'
    document.documentElement.dataset.theme = stored || preferred
  } catch(e) {}
})()`

export default function App() {
  return (
    <html lang="en">
      <head>
        <script dangerouslySetInnerHTML={{ __html: themeScript }} />
        <Meta />
        <Links />
      </head>
      <body>
        <Outlet />
        <ScrollRestoration />
        <Scripts />
      </body>
    </html>
  )
}
```

<Callout>
The script must be a plain inline script — not `async`, not `defer`, not a module. It needs to block rendering so the attribute is set before the browser paints anything.
</Callout>
