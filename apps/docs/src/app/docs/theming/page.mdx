# Theming

tokiui uses CSS custom properties (variables) for all colors and border radius. Change the entire look of your app by overriding a few variables — no component changes required.

## How it works

All components use semantic Tailwind classes like `bg-primary` and `text-muted-foreground`. These map to CSS variables via the `@theme` block in `@tokiui/ui/styles.css`:

```css
@theme {
  --color-primary: var(--primary);
  --color-muted-foreground: var(--muted-foreground);
  /* ... */
}
```

The actual OKLCH values live in `:root` (light) and `[data-theme="dark"]` (dark mode):

```css
:root {
  --primary: oklch(0.74 0.17 118);
}
[data-theme="dark"] {
  --primary: oklch(0.78 0.17 118);
}
```

## Customizing your theme

Override any variable in your `globals.css` after the import:

```css
@import "tailwindcss";
@import "@tokiui/ui/styles.css";

:root {
  --primary: oklch(0.65 0.20 270);  /* purple */
  --radius: 14px;                    /* rounder corners */
}
[data-theme="dark"] {
  --primary: oklch(0.72 0.18 270);
}
```

## Using the playground

Visit the [Playground](/playground) to adjust every token visually. When you're happy, click **Copy CSS variables** and paste the output into your `globals.css`, or click **Copy theme URL** to share the exact theme.

## Dark mode

Dark mode is controlled by the `data-theme="dark"` attribute on `<html>`. Toggle it with JavaScript:

```ts
document.documentElement.dataset.theme = 'dark'
document.documentElement.dataset.theme = 'light'
```

Use the `useTheme` hook from `@tokiui/ui/client` for a localStorage-persisted toggle:

```tsx
'use client'
import { useTheme } from '@tokiui/ui/client'

export function ThemeToggle() {
  const [theme, toggle] = useTheme()
  return <button onClick={toggle}>{theme}</button>
}
```
