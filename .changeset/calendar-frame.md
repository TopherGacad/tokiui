New frame: **calendar** — a responsive month / week / day calendar with colored event blocks, overlap-aware layout, a live now-indicator, click-to-add, and event detail. Install with `npx @tokiui/cli add calendar` (drops into `components/frames/calendar/` and wires a ready `/calendar` route). Events are a plain `CalendarEvent[]`, so swapping the sample data for your own is a one-file change.
